# 오픈소스 소프트웨어 텀프로젝트

## 주제 선정
평소에 피아노를 한번씩 연주하는데 새로운 악보를 연주할 때마다 음이 익숙하지 않아 맞는 음을 연주해도 불협화음처럼 들리는 때가 종종 있었음. 이럴 때마다 악보만 있어도 원래 연주를 들어볼 수 있는 소프트웨어가 있었으면 좋겠다고 생각함. 그래서 '악보를 바탕으로 미디파일을 만들어주는 소프트웨어'라는 주제를 선정함.

## 1일차
OpenCV 알고리즘을 이용하기 위해 악보 색 반전을 통한 이진화된 악보 생성 구현. 이진화된 악보에서 오선 / 음표 및 악상기호들을 분리하여 새로운 이미지로 생성.

## 2일차
복잡한 악보를 넣었더니 악보 전처리가 이상하게 되고 해상도가 많이 떨어졌음. 코드를 다시 구성하였지만
여전히 같은 문제가 반복됨. 아예 구조를 처음부터 다시 설계했지만 여전히 음표 인식에서 문제가 생김

## 3일차
musicXML오픈소스를 활용해 악보 이미지의 미디 전환 확인
해당 과정에서 필요한 라이선스들을 정리함

## 4일차
GUI의 기본 기능을 구현함.
악보 이미지 추가 - PNG, JPG, JPEG, TIF, TIFF 파일을 선택할 수 있음. 여러 파일을 한 번에 추가할 수 있고, 같은 파일이 중복으로 들어가는 것은 안됨
선택한 악보 삭제 - 목록에서 선택한 파일을 대기열에서 제거함
저장 폴더 선택 - MIDI 파일을 저장할 폴더를 지정할 수 있음. 기본 폴더는 프로젝트의 outputs폴더
대기열 순차 변환 - 악보를 한 장씩 차례로 변환 변환 중에도 창이 멈추지 않도록 별도 작업 스레드에서 처리합니다.
파일별 결과 표시 - 목록에 각 파일의 변환 중, 완료 또는 실패 상태를 표시함 한 파일이 실패해도 다음 파일을 계속 처리함
전체 진행률 표시 - 대기열 중 몇 퍼센트까지 처리했는지 표시함
기존 결과 보호 - 같은 이름의 MIDI 파일이 저장 폴더에 이미 있으면 _2, _3처럼 번호를 붙여 저장함
변환 중 조작 제한 - 작업이 진행되는 동안 파일 목록이나 저장 폴더를 바꾸지 못하게 하고, 변환 중 창을 닫으려 하면 안내알림 등장함

## 5일차
사용자가 GUI에서 Audiveris.exe의 경로를 직접 선택할 수 있는 기능을 추가함, 잘못된 경로가 지정되면 변환 전에
안내 메세지를 표시하도록 함
Audiveris의 출력을 CP949로 읽으면서 오류가 발생했는데, Audiveris의 출력을 바이트 형태로 받아서 UTF-8로 변환하도록 수정함.
처음 작은별 악보를 테스트해봤을 때 악보 해상도가 낮아 오선 간격을 6픽셀로 판단하여 처리를 중단함.
이미지 긴 쪽이 1600픽셀보다 작으면 자동으로 확대하도록 전처리를 추가함. 이후 변환된 미디파일이 잘 저장되는 것을 확인함.

## 6일차
악보 이미지를 여러장 입력하여 MIDI파일 하나로 변환하는 기능을 구현함.
해당 과정에서 단순한 양손악보는 변환에 문제가 없지만 복잡한 악보를 샘플로 사용하면 음이 밀리거나 악기소리가
달라지는 등 다양한 문제가 발생함. 이미지(jpg, png)뿐만 아니라 pdf파일도 악보로 입력할 수 있는 기능을 구현하고
확장자는 여러개 중복해서 사용이 불가하도록 설정함. 악기소리를 피아노소리로 고정함.

## 7일차
여러 페이지로 구성된 피아노 악보 PDF를 MIDI로 변환하는 기능을 점검함. Audiveris가 오른손과 왼손의 마디 길이를 서로 다르게 인식하면서 연주 시점이 점점 어긋나는 문제를 확인함.
이를 개선하기 위해 오른손과 왼손이 동일한 마디 시작점을 사용하도록 리듬 보정 코드를 수정함. 그 결과 마디 단위의 누적 싱크 오차는 줄일 수 있었음.
추가로 악보인식 과정에서 발생한 문제일 수도 있어서 악보를 단순히 확대하여 Audiveris가 인식할 수 있도록
한 것이 아닌 전처리 코드를 따로 추가하여 gui와 연결함.
하지만 16분음표가 포함된 마디나 악상기호가 많은 복잡한 구간에서는 음표가 정확한 박자에 연주되지 않는 문제가 남아 있었음.

MusicXML의 세부 음표 길이와 마디 내부 위치를 분석해 박자 보정 기능을 개선예정
