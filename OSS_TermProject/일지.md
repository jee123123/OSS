# 오픈소스 소프트웨어 텀프로젝트

## 주제 선정
평소에 피아노를 한번씩 연주하는데 새로운 악보를 연주할 때마다 음이 익숙하지 않아 맞는 음을 연주해도 불협화음처럼 들리는 때가 종종 있었음. 이럴 때마다 악보만 있어도 원래 연주를 들어볼 수 있는 소프트웨어가 있었으면 좋겠다고 생각함. 그래서 '악보를 바탕으로 미디파일을 만들어주는 소프트웨어'라는 주제를 선정함.

## 1일차
OpenCV 알고리즘을 이용하기 위해 악보 색 반전을 통한 이진화된 악보 생성 구현. 이진화된 악보에서 오선 / 음표 및 악상기호들을 분리하여 새로운 이미지로 생성.

## 2일차
복잡한 악보를 넣었더니 악보 전처리가 이상하게 되고 해상도가 많이 떨어졌음. 코드를 다시 구성하였지만
여전히 같은 문제가 반복됨. 아예 구조를 처음부터 다시 설계했지만 여전히 음표 인식에서 문제가 생김

## 3일차
musicXML오픈소스를 활용해 악보 이미지의 미디 전환 확인
해당 과정에서 필요한 라이선스들을 정리함

## 4일차
GUI의 기본 기능을 구현함.
악보 이미지 추가 - PNG, JPG, JPEG, TIF, TIFF 파일을 선택할 수 있음. 여러 파일을 한 번에 추가할 수 있고, 같은 파일이 중복으로 들어가는 것은 안됨
선택한 악보 삭제 - 목록에서 선택한 파일을 대기열에서 제거함
저장 폴더 선택 - MIDI 파일을 저장할 폴더를 지정할 수 있음. 기본 폴더는 프로젝트의 outputs폴더
대기열 순차 변환 - 악보를 한 장씩 차례로 변환 변환 중에도 창이 멈추지 않도록 별도 작업 스레드에서 처리합니다.
파일별 결과 표시 - 목록에 각 파일의 변환 중, 완료 또는 실패 상태를 표시함 한 파일이 실패해도 다음 파일을 계속 처리함
전체 진행률 표시 - 대기열 중 몇 퍼센트까지 처리했는지 표시함
기존 결과 보호 - 같은 이름의 MIDI 파일이 저장 폴더에 이미 있으면 _2, _3처럼 번호를 붙여 저장함
변환 중 조작 제한 - 작업이 진행되는 동안 파일 목록이나 저장 폴더를 바꾸지 못하게 하고, 변환 중 창을 닫으려 하면 안내알림 등장함
